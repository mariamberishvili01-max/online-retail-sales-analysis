# Online Retail Sales Analysis 🛒 | Python

## Overview
Exploratory data analysis of a real-world online retail dataset 
containing 541,909 transactions across 38 countries, performed 
using Python in Google Colab.

## Tools & Libraries
- Python, Pandas, NumPy, Matplotlib, Seaborn

## Dataset
- Source: Online Retail Dataset (UCI Machine Learning Repository)
- 541,909 rows | 8 columns
- Time period: December 2010 – December 2011

## Analysis Performed
- Data cleaning: removed nulls, duplicates, and negative quantities
- Revenue calculation and product-level profitability analysis
- Sales trend analysis by month, day, and hour
- Country-level revenue distribution
- Top customers by revenue contribution

## Key Findings
- Top product by revenue: DOTCOM POSTAGE
- UK accounts for the majority of all transactions (~90%)
- Peak sales hours: 10AM – 1PM
- Best performing days: Wednesday and Thursday
- November and December are the highest revenue months
- ~25% of transactions had missing Customer IDs (unregistered users)
